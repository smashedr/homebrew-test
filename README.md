Use the live tap instead:

## Brew Commands

Debug

```shell
export HOMEBREW_VERBOSE=1
```

Tap

```shell
brew tap smashedr/test
brew tap smashedr/homebrew-test
brew tap smashedr/homebrew-test https://github.com/smashedr/homebrew-test
```

Install

```shell
brew install npmstat
brew install smashedr/test/npmstat
brew install smashedr/homebrew-test/npmstat
```

Update

```shell
brew update
brew reinstall npmstat

brew update && brew reinstall npmstat
```
